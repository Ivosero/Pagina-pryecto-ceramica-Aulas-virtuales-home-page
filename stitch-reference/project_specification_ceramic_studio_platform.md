# Ceramic Art Studio Platform - Product Requirements Document

## 1. Project Overview
A dual-purpose platform for a ceramic artist:
- **Public Website:** To showcase the studio, the artist's philosophy, and sell online/offline courses.
- **LMS (Learning Management System):** A private area for students to consume purchased content and for admins to manage the business.

## 2. Information Architecture

### Public Website
- **Home:** Hero, Intro, Featured Courses, About the Artist, Testimonials, Newsletter.
- **Courses:** Grid of available courses with filters (Level, Format).
- **Course Detail:** Comprehensive sales page with curriculum, price, and "Enroll" CTA.
- **About:** Studio story, philosophy, and photos.
- **Contact:** Form, studio details, and FAQ links.

### Authentication
- Login, Sign Up, Forgot Password, Reset Password, Email Verification.

### Student Area (Virtual Classroom)
- **Dashboard:** Welcome, progress tracking, "Continue Learning" shortcuts.
- **My Courses:** Library of purchased content.
- **Course Overview:** Module/Lesson list for a specific course.
- **Lesson Experience:** Video player, text content, downloadable PDFs, navigation (Prev/Next), and completion tracking.
- **Profile:** Account settings and progress history.

### Admin Panel
- **Dashboard:** Analytics (Students, Revenue, Activity).
- **Students:** User list, profile views, manual enrollment.
- **Courses:** Catalog management, publishing controls.
- **Editors:** Specialized tools for creating Modules and Lessons (Video embeds, File uploads).
- **Enrollments:** Tracking student progress and access.

## 3. Visual Direction
- **Vibe:** Warm, artisanal, premium, approachable.
- **Palette:** Ivory, Terracotta, Sand, Charcoal.
- **Shapes:** Organic, soft corners.

## 4. Technical Requirements
- Mobile-responsive across all areas.
- Clear distinction between Public, Student, and Admin UI while maintaining brand cohesion.
